# Extending Codex: Building Custom Tools, Skills, and Integrations

Learn how to extend Codex with project instructions, MCP tools, APIs, and persistent storage. This five-chapter series uses **TaskHub**, a small task manager, as a running example. Each chapter builds on the previous one, from a local MCP server to a Google Drive integration.

## Chapters

1. [Understanding Codex Extensibility](tutorials/01-understanding-codex-extensibility.md) — the roles of instructions, skills, MCP, APIs, and storage.
2. [Building Your First Codex MCP Server](tutorials/02-building-your-first-mcp-server.md) — build a local task core, JSON store, and MCP tools.
3. [Building Reliable MCP Tools](tutorials/03-building-reliable-mcp-tools.md) — add revisions, idempotency, validation, and recovery.
4. [Choosing Cloud Storage for a Codex MCP Integration](tutorials/04-choosing-cloud-storage.md) — understand Google Drive, Google Cloud, OAuth, and costs.
5. [Integrating Google Drive with a Codex MCP Server](tutorials/05-integrating-google-drive.md) — connect TaskHub to a disposable Drive JSON file.

Start with [Chapter 1](tutorials/01-understanding-codex-extensibility.md), or browse the [tutorial index](tutorials/README.md) for milestone and verification notes.

The Google Drive walkthrough was verified with disposable data on one computer. Second-computer use and migration of real tasks remain untested.
